# VacationScheduler
Repo to host Vacation Scheduler app for WGU capstone class

Introduction
    This guide provides comprehensive instructions on how to install, access, and use all functions of the Vacation Scheduler application. The steps below detail how to navigate the interface, manage travel itineraries, add excursions, set alerts, and generate summary reports.

Installation and Access
    1.	Download the application's .apk installation file to your Android device.
    2.	Tap the file to install the application. (Note: You may need to allow "Install from Unknown Sources" in your device settings).
    3.	Once installed, locate the "Vacation Scheduler" icon in your app drawer and tap to launch it.

Navigating the Main Menu
    1.	Upon opening the application, you will see the home screen featuring the application title and a background image.
    2.	Click the purple "Enter Application" button to proceed to the main dashboard.
    Viewing and Searching Vacations
    1.	After entering the application, the Vacation List screen displays all currently saved trips.
    2.	To quickly populate the application with testing data, click the three-dot overflow menu in the top right corner and select "Add Sample Vacation".
    3.	To search for a specific trip, click the magnifying glass icon in the top right corner and type the name of the vacation. The list will instantly filter to match your input.


Adding and Modifying Vacations
    1.	To create a new vacation, click the circular "+" floating button at the bottom right of the Vacation List screen.
    2.	Enter the Vacation Title, Hotel Name, and Price using the provided text boxes.
    3.	Click the Start Date and End Date fields to select your travel dates from a calendar. The application will automatically prevent you from saving if the end date occurs before the start date.
    4.	Once all fields are populated, click the three-dot overflow menu in the top right corner and select "Save".
    5.	To delete a vacation, navigate to its details screen, open the overflow menu, and select "Delete". (Note: You cannot delete a vacation if it currently has excursions attached to it).
Adding Excursions to a Vacation
    1.	To add an activity to a trip, tap on any saved Vacation from the list to open its details.
    2.	Click the circular "+" button at the bottom right of the Vacation Details screen.
    3.	Enter the Excursion Title, Price, and Date. The excursion date must fall between the start and end dates of the associated vacation.
    4.	Add any specific details or reminders to the Notes box.
    5.	If you wish to share these notes, click the top overflow menu and select "Share" to send the text via email or SMS.
    6.	Click "Save" in the top menu to attach the excursion to the vacation.
Setting Alerts
    1.	To set a reminder for your travel, open the details screen for any saved Vacation or Excursion.
    2.	Click the top right overflow menu and select "Notify".
    3.	The application will schedule a push notification to alert you at 9:00 AM on the saved dates.
Generating Reports
    1.	To view a complete summary of your travel data, return to the main Vacation List screen.
    2.	Click the three-dot overflow menu in the top right corner and select "Generate Report".
    3.	A dedicated report screen will appear, displaying a timestamp of exactly when the report was generated, alongside a multi-column table detailing the names, hotels, start dates, and prices of all saved vacations.
